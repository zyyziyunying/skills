## Read Before Editing

- Read `SPEC.md` or the linked product spec before interpreting goals, current behavior, compatibility posture, assumptions, or acceptance criteria.
- Read `ARCHITECTURE.md` before changing module boundaries, dependencies, layers, shared interfaces, or cross-cutting concerns.
- Read `TEST.md` or the linked quality source before adding tests, judging evidence, running conditional commands, or analyzing runtime bugs.
- Read `DESIGN.md` or the relevant design-doc index before changing user experience, interaction, visual behavior, or established design principles.
- Read the active execution plan before continuing complex work; update its progress and decision record without copying current facts into it.
- Read `GENERATION.md` before editing, deleting, regenerating, or validating generated files.
- Read `LOCAL.md` before changing local setup, debug configuration, run instructions, secrets, or machine-local files.
- Read `PACKAGING.md` before changing identity, signing, versioning, artifacts, publishing, installation, or deployment behavior.

Omit entries that do not exist. Link to the actual owner when the repository uses
an indexed `docs/` source instead of a root-level file.
